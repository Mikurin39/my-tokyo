# Googleカレンダー連携のセットアップ（5分・無料）

予約フォーム → あなたのGoogleカレンダーに自動でイベント作成 + 確認メール送信、
さらにカレンダーの既存予定がサイト上で「予約不可」としてグレーアウトされます。

## 手順

1. https://script.google.com を開く（mikumaketer1@gmail.com でログイン）
2. **「新しいプロジェクト」** をクリック
3. エディタに `Code.gs` の中身を全部貼り付けて保存（プロジェクト名: `My Tokyo Booking`）
4. 右上 **「デプロイ」→「新しいデプロイ」**
   - 種類の選択（歯車アイコン）→ **ウェブアプリ**
   - 説明: 任意
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員** ← 重要（サイトから匿名アクセスするため）
5. **「デプロイ」** → 初回はアクセス承認を求められる
   - 「権限を確認」→ 自分のアカウント選択 → 「詳細」→「（安全ではないページに）移動」→ 許可
   - （カレンダー・メール送信の権限。自分で書いたスクリプトなので問題ありません）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/XXXX/exec`）をコピー
7. `index.html` の `CONFIG.GAS_URL` に貼り付け:

   ```js
   const CONFIG = {
     GAS_URL: "https://script.google.com/macros/s/XXXX/exec",
     ...
   ```

8. サイトを再デプロイ（git push）して完了 🎉

## 動作確認

- サイトの予約フォームからテスト予約 → 自分のGoogleカレンダーにイベントが入り、
  入力したメールアドレスに確認メールが届けばOK
- カレンダーに手動で予定を入れる → サイト側でその時間帯が予約不可になる
  （終日予定を入れるとその日全体がグレーアウト＝休業日として使えます）

## 注意

- Code.gs を修正したら「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」で更新
  （URLは変わりません）
- MailApp の無料枠は 100通/日（個人アカウント）。予約サイトには十分です
